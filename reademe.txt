При первом запуске необходимо создать в корне сайта директории:

storage/data
storage/contract
storage/act

Перейти в директорию docker_dev и выполнить следующие команды:

docker compose run composer install --ignore-platform-reqs

Или 

docker-compose run composer install --ignore-platform-reqs

Для более старых версий Docker


Запустить сервер:
Перейти в директорию docker и выполнить следующие команды:

docker compose up
docker compose up -d // запуск в фоновом режиме

Остановить:

docker compose down

Сервер доступен по адресу: http://localhost:3000



Команды Docker:

————————————————————— Контейнеры ———————————————————————

Посмотреть запущенные контейнеры:
  sudo docker ps -a

Войти в запущенный контейнер:
  sudo docker exec -it [NAMES | CONTAINER ID] /bin/sh
  sudo docker exec -it laravel-laurent-web-1 /bin/sh
  (выход: exet)

Остановить контейнер:
  sudo docker [NAMES | CONTAINER ID] stop

Удалить контейнер или несколько сразу:
  sudo docker rm [NAMES | CONTAINER ID]     // можно указывать только несколько первыйх символов CONTAINER ID и указывать их через пробел если нужно несколько
  sudo docker rm d3 58 dc

————————————————————————————————-———————————————————————


————————————————————— Образы ——————————————————————————-

Посмотреть образы:
  sudo docker images

Удалить образ или несколько:
  sudo docker rmi [TAG | IMAGE ID]    // можно указывать только несколько первыйх символов IMAGE ID и указывать их через пробел если нужно несколько
  sudo docker rmi 3c b4 93 11 

Удалить все образы:
  sudo docker rmi $(docker images -q)
